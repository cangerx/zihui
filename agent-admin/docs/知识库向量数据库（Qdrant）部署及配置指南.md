# 知识库向量数据库（Qdrant）部署配置指南

> 适用对象：云控端运维 / 部署人员
> 目标：用**宝塔面板的 Docker** 部署 Qdrant 向量数据库，并在**云控端后台**填好连接信息，让「知识库」功能可以向量化与检索。

---

## 0. 它是干什么的

云控端「知识库」的文档会被切片并转成向量，存进 **Qdrant 向量数据库**。智能体对话时，桌面端在线检索这些向量来作答。

- **不配置 Qdrant**：知识库无法向量化、检索不可用（后台「知识库设置」会显示「Qdrant 未连通」）。
- 连接信息（地址 / API Key / Collection）**全部在云控端后台填写，无需改服务器 `.env`**。

部署形态二选一：

- **形态 A：Qdrant 与云控端在同一台服务器**（多数情况，最简单）
  - IP 用法：内网 IP / `127.0.0.1`
  - 是否需放行端口：否
- **形态 B：Qdrant 与云控端在不同服务器**（想单独部署向量库）
  - IP 用法：公网 IP
  - 是否需放行端口：是（容器对外暴露 + 安全组放行 6333）

## 1. 用宝塔 Docker 部署 Qdrant

### 1.1 进入 Docker

宝塔面板左侧菜单 → **Docker**（首次使用会提示安装 Docker 服务，按提示一键安装即可）。

### 1.2 搜索镜像并创建容器

1. 进入 **Docker → 镜像 → 线上（在线搜索）**，搜索框输入 `qdrant`。
2. 在搜索结果中找到镜像名为 **`qdrant/qdrant`** 的官方镜像，直接点该行的「**创建容器**」（本地没有该镜像时会自动在线拉取）。
3. **容器名称**：随意命名，例如 `qdrant`。

### 1.3 端口映射（关键）

在「端口」处点 **添加** 一条映射：

- **本地端口（宿主）**：填 `6333`（云控端连接用的端口）
- **容器端口**：填 `6333`（Qdrant 的 HTTP/REST API 端口）
- **对外暴露**：同机**不勾**、跨服务器**勾选**（见下方说明）

> - **Qdrant 与云控端同一台服务器**：不用勾「对外暴露」，云控端走内网即可，更安全。
> - **Qdrant 与云控端不在一台服务器**：勾选「对外暴露」，并在 **1.5** 放行端口。

### 1.4 数据持久化（强烈建议）

默认情况下容器删除后向量数据会丢失。建议在「目录映射 / 挂载」处加一条，把向量数据存到宿主机：

- **宿主目录**：`/www/qdrant/storage`（自定义，确保已存在 / 可写）
- **容器目录**：`/qdrant/storage`

> 不做持久化也能用，但**重建/删除容器会丢全部向量**，需要重新向量化所有文档。生产环境务必映射。

填好后点「提交 / 创建」，等容器状态变为 **运行中**。

### 1.5 放行端口（仅跨服务器时需要）

当 Qdrant 与云控端**不在同一台服务器**时：

1. 宝塔面板 → **安全**（或服务器防火墙）→ 放行端口 `6333`。
2. 若是云服务器（阿里云 / 腾讯云等），还需到对应控制台的**安全组**放行 `6333`。

> 同一台服务器内网互通，**不需要**放行 6333。

---

## 2. 在云控端后台填写连接信息

1. 登录云控端管理后台。
2. 左侧菜单 → **知识库管理 → 知识库设置**。
3. 找到「**Qdrant 向量库连接**」卡片，填写：

- **服务地址（URL）**：填 `http://IP:端口`
  - 同机：`http://127.0.0.1:6333` 或内网 `http://192.168.x.x:6333`
  - 跨服务器：`http://公网IP:6333`
- **API Key**：可选；Qdrant 默认无鉴权时**留空**（详见「3. 安全建议」）
- **Collection 名**：留空即用默认 `kb_chunks`

4. 点「**保存设置**」。
5. 保存后，卡片内与顶部统计会刷新连通状态：
   - 显示「**Qdrant 已连通**」= 配置成功。
   - 显示「**Qdrant 未连通**」= 见「4. 排错」。

> URL 必须带 `http://` 前缀；末尾不要加 `/`（加了也会自动去掉）。

### 2.1 下一步：选向量模型

连通成功后，还需在同一页的「**向量模型（embedding）**」卡片选择一个 embedding 模型（来自「AI 资源 → 模型管理」中 `type=embedding` 且启用的模型），点「测试连通」确认可用并保存，知识库文档才能开始向量化。

---

## 3. 安全建议（公网暴露时务必看）

如果 Qdrant **对公网暴露**（跨服务器场景），**强烈建议开启 API Key 鉴权**，否则任何人都能读写你的向量库。

开启方式：在宝塔创建/编辑容器时，**环境变量**处添加：

```
QDRANT__SERVICE__API_KEY=你的高强度密钥
```

然后在云控端「知识库设置 → Qdrant 向量库连接 → API Key」填入**同一个密钥**并保存。

> - 同机内网部署（不对外暴露）通常可不设 API Key。
> - 后台保存的 API Key 为**加密存储**，不会明文下发到前端。
> - 已配置过 API Key 后，再次编辑时该框留空表示「保持不变」，不会被清空。

---

## 4. 排错（显示「Qdrant 未连通」）

按下面逐项排查：

1. **容器是否在运行**：宝塔 Docker → 容器，确认状态为「运行中」；可点日志查看是否报错。
2. **URL 是否正确**：
   - 同机用 `http://127.0.0.1:6333` 或内网 IP；
   - 跨服务器用**公网 IP**，且容器已勾「对外暴露」。
3. **端口是否放行**（跨服务器）：宝塔安全 + 云服务器安全组都要放行 `6333`。
4. **协议/格式**：必须是 `http://`（自建未配 TLS 时不要写 `https://`）。
5. **本机自检**：在 Qdrant 所在服务器执行，应返回 JSON：

```bash
curl http://127.0.0.1:6333/healthz
# 或
curl http://127.0.0.1:6333/
```

6. **设了 API Key 却连不上**：确认后台填的 Key 与容器环境变量 `QDRANT__SERVICE__API_KEY` **完全一致**。

---

## 5. 运维提示

- **备份**：定期备份持久化目录（`/www/qdrant/storage`）即可保留全部向量。
- **更换 embedding 模型 / 维度变化**：不同 embedding 模型维度可能不同，更换后需对各知识库重新「重建索引」（在「知识库列表」对每个库点「重建」）。
- **升级 Qdrant**：拉取新版 `qdrant/qdrant` 镜像后重建容器；只要持久化目录不变，数据不丢。
- **多实例 / 多站点**：可用不同 `Collection 名` 或不同 Qdrant 实例隔离；本系统默认单 collection（`kb_chunks`），内部按知识库 ID 自动隔离，一般无需改 Collection。

---

## 附：最简流程速查

1. 宝塔 Docker → 镜像 → 线上搜索 `qdrant` → 在 `qdrant/qdrant` 那一行点「创建容器」→ 命名 `qdrant`。
2. 端口加 `6333:6333`（跨服务器再勾「对外暴露」+ 放行 6333）。
3. 挂载 `/www/qdrant/storage → /qdrant/storage`（持久化）。
4. 启动容器。
5. 后台「知识库管理 → 知识库设置 → Qdrant 向量库连接」填 `http://IP:6333` → 保存 → 显示「已连通」。
6. 选 embedding 模型 → 开始建库、上传文档、向量化。
