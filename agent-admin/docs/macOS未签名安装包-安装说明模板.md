## 为什么 macOS 提示「包含恶意软件」？

本应用当前未做 Apple 开发者签名与公证。macOS 15 及更高版本会把**浏览器下载的未签名应用**统一按「包含恶意软件」处理并移入废纸篓——这是系统对未签名应用的默认策略，**并非应用真的含有恶意代码**。

按下面任一方式安装即可，**只有首次安装需要**，之后正常使用和在线更新都不受影响。

## 方案 A（推荐）：终端一键安装，全程无弹窗

原理：用命令行下载的文件不带「隔离」标记，系统不会拦截。

1. 打开「终端」（启动台搜索 `Terminal`，或「应用程序 → 实用工具 → 终端」）
2. 粘贴下面这行命令，回车执行：

   ```bash
   cd /tmp && curl -LO "{{下载地址}}" && ditto -x -k "{{zip文件名}}" /Applications/ && rm "{{zip文件名}}"
   ```

3. 执行完成后，到「应用程序」文件夹打开 **{{应用名}}**

> 若机器上安装过旧版，请先把旧版从「应用程序」拖入废纸篓，再执行上面的命令。

## 方案 B：图形界面安装（已下载但被系统拦截时用这条）

1. 重新下载安装包：{{下载地址}}
2. 双击下载好的 zip 解压。**请务必使用系统自带的「归档实用工具」**（双击默认即是），不要用第三方解压软件——它们会破坏应用内部结构，导致报「已损坏」
3. 把 **{{应用名}}.app** 拖进「应用程序」文件夹
4. 打开「终端」，粘贴执行下面这行命令（作用：移除系统给下载文件打的「隔离」标记）：

   ```bash
   xattr -cr "/Applications/{{应用名}}.app"
   ```

5. 正常打开应用

## 常见问题

**Q：这样安装安全吗？**
安全。上述操作只是告诉系统「信任这个来自官方渠道的应用」，与应用本身无关。请确认下载地址来自官方提供的渠道。

**Q：之后的在线更新还要这样操作吗？**
不需要。应用内下载的更新包不带隔离标记，不会触发拦截。

**Q：打开提示「已损坏，无法打开」？**
多半是解压方式不对。删掉解压出的应用，改用系统自带「归档实用工具」重新解压（右键 zip → 打开方式 → 归档实用工具）。

**Q：公司统一管控的 Mac 装不上？**
受企业管理（MDM）策略限制的 Mac 可能禁止运行未签名应用，请联系公司的 IT 管理员放行。
